# Neuracore

> Neuracore is an end-to-end cloud platform for robot skill creation: collect teleoperation demonstrations, curate and version datasets, train imitation-learning and reinforcement-learning policies, and deploy them to production robots for real-time inference. It is driven by an official Python SDK and CLI (`pip install neuracore`) that stream 14 first-class data modalities to the Neuracore backend at api.neuracore.com. Authentication uses a Neuracore API key (nrc_ prefix) or interactive login, scoped to an organization.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public developer surface (Neuracore does not publish its own llms.txt).

## API
- Base URL: https://api.neuracore.com/api (staging: https://staging.api.neuracore.com/api)
- Auth: API key `nrc_` via `NEURACORE_API_KEY`, or `neuracore login`; org via `NEURACORE_ORG_ID`
- Consumed by the official SDK/CLI; no public OpenAPI document is currently published.
